# 示例画像：阿澈（虚构人物）

> ⚠️ **本示例完全虚构**。人物、数据、结论均为演示格式而编造，不对应任何真实个人。
> 数据来源标注为「合成数据」，仅用于展示 `tact-profile` 的输出形态。

## 输入（合成）

| 数据 | 规模 |
| --- | --- |
| 朋友圈 | 3 年，约 600 条 |
| 游戏库 | 120 款 / 2100 小时 |
| 问答 | 20 问全填 |

---

## L1 一页卡

### 一句话

> **一个用「完成度」衡量自己、用「共处」衡量关系的人——对效率有执念，对人有耐心。**

### 五个关键词

| 词 | 含义 | 证据 |
| --- | --- | --- |
| 完成感 | 事情没做完会不舒服 | A（问答）+ B（成就率） |
| 效率 | 讨厌重复劳动，能自动化就自动化 | A |
| 低冲突 | 回避争论，不主动挑事 | B（朋友圈无争吵） |
| 收集癖 | 喜欢把东西分类、归档 | B（截图 4000+ 张） |
| 慢热 | 关系建立慢，但维持久 | A |

### 三条建议

1. 给他「有边界的任务」——明确验收标准，他会自己跑到线。
2. 别用即时反馈催他；他的节奏是「攒一批再处理」。
3. 关系上先找共同活动，不要先谈感情。

### 三个缺口

- 家庭情况（只知独生）
- 压力的承受阈值
- 对「失败」的真实反应

---

## L2 节选（演示十维里的三维）

### 节律

| 时段 | 活跃度 |
| --- | --- |
| 09–12 | 低 |
| 14–18 | 中 |
| **22–01** | **高** |

**推断（C 级）**：夜型，白天被打断多，晚上才有一段完整时间。

### 消费

| 类 | 行为 |
| --- | --- |
| 游戏 | 买断为主；DLC 只买「有剧情」的 |
| 抽卡 | 有硬上限（每月一次十连） |
| 数码 | 换代周期 4 年，坏才换 |

**推断（C 级）**：**要确定性**——为「一定会拿到的东西」付钱，不为概率付钱。

### 社交

| 层 | 模式 |
| --- | --- |
| 固定群 | 3 个，都是「共同活动」起家（桌游、游戏、读书） |
| 同事 | 座位近的常聊，调岗即断 |
| 主动 | 需要理由才联系 |

**结论（A 级）**：关系由「共同活动」维持，不由「感情维护」维持。

## 张力（演示）

| 张力 | 一侧 | 另一侧 |
| --- | --- | --- |
| 效率 vs 完整 | 讨厌重复劳动 | 又忍不住把东西整理完 |
| 低冲突 vs 有立场 | 回避争论 | 对某些事很坚持 |
| 慢热 vs 重关系 | 不主动 | 老朋友维持十年 |

## 缺口

- 家庭（只知独生）
- 压力阈值（没见过崩的时刻）
- 对失败的反应（没记录）

---

## 这份示例想说明什么

1. **判断要有级别**——A/B/C 分开，不混着说。
2. **事实与判断分层**——「600 条时间分布」是事实，「夜型」是判断。
3. **张力比标签有用**——「低冲突 + 有立场」比「温和」准确。
4. **缺口要诚实**——不知道就写不知道。
