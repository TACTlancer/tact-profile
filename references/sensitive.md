# 敏感维度：亲密关系与性脚本（可选）

**默认关闭。** 只有本人主动提出、并主动提供材料时才做。不从浏览记录、消费记录、聊天内容反推——反推敏感属性是红线。

定位：这是画像里**最靠后、最靠边**的一维。有它，人的完整性更好；没有，也不影响主结论。

---

## 三条线

| 线 | 内容 | 证据要求 |
| --- | --- | --- |
| **可写** | 态度倾向、关系模式、脚本来源、需求结构 | A 级（本人陈述） |
| **谨慎** | 偏好类别（只写类型名，不写细节）、经验多寡（只写"有/无/不答"，不量化不比较） | 逐条经本人确认 |
| **不写** | 行为细节与频率、身体描述、取向推断、临床判断、第三方、未成年人 | 一律不做 |

---

## 可写的四块

### 1. 态度倾向
用 BSAS 的四个维度做**参照**（不打分、不比较人群）：
- 宽容度：对非承诺关系 / 多元关系的接受度
- 责任：对避孕、健康、后果的态度
- 融合：亲密与情感联结的重要程度
- 身体：对纯粹身体愉悦的态度

写法：每维一句，用「更看重 / 不太在意 / 说不清」。

### 2. 关系模式
- 依恋：安全 / 焦虑 / 回避 / 混合（按自述判断，不套标签）
- 边界：什么算越界、怎么表达
- 冲突：修复方式（说开 / 冷处理 / 回避）
- 节奏：快热 / 慢热 / 条件驱动

### 3. 脚本来源
性脚本理论的三层，用来问「这些观念从哪来」：
- 文化场景：家庭、学校、同辈、媒介
- 人际脚本：上一次关系里学到什么
- 内心脚本：他自己怎么解释自己的选择

**这是最有价值的一块**——它比「他喜欢什么」更能说明他是谁。

### 4. 需求结构
亲密关系里他真正要什么：陪伴 / 身体 / 被认可 / 自由 / 安全感。允许并列，允许"都要一点"。

---

## 用词规则

- 用中性词：不说俚语，不做器官描写，不用「骚/浪/纯」这类评价词。
- 不判断正常与否：用「常见 / 少见」「在他的语境里」代替「正常 / 不正常」。
- 不评价健康与否：不写「健康」「病态」「有问题」。
- 不用量表分数给结论：可以说「更接近 A 端」，不写「得 3.2 分」。

## 提问方式（本人愿意时）

1. **先问看法，不问经历**：「你怎么看 X」比「你有没有 X」安全得多。
2. **给选项，不开放式**：降低尴尬，也降低表演。
3. **允许跳过**：跳过不记缺口，不追问。
4. **一次不超 5 题**，分多轮。
5. **先自我暴露再提问**：先说「这个维度大多数人只答一部分」，再问。

示例问法：
- 「亲密关系里你更怕被束缚还是被忽略？」
- 「你觉得性是关系的一部分，还是独立的事？」
- 「你对'承诺'的定义是什么？」
- 「有你绝对不接受的事吗？（可以不答）」

---

## 红线（写死）

1. 不生成露骨内容，不做行为描写。
2. 不推断性取向——除非本人明确说过。
3. 不做临床判断（障碍、创伤、成瘾）。
4. 不涉及未成年人。
5. 不写第三方可识别信息。
6. 不因为「数据里有」就写；只因为「本人说了」才写。
