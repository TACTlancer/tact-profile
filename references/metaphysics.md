# 玄学附录规范

玄学材料 = **emic 数据**（当事人自己的框架）。写进附录，不参与主结论。

## 处理原则

| 原则 | 说明 |
| --- | --- |
| 位置 | 只在附录（`## 附录：自我叙事与象征系统`） |
| 标注 | 每条标「本人认同 / 半信 / 不信 / 未问」 |
| 不混算 | 不和 B 级行为数据并列成「证据」 |
| 可引用 | 可以作为提问线索（"命盘说事业宫强，你怎么看"） |
| 不证伪 | 不评价准不准，只记录「他信什么、怎么用」 |

## 常见材料的接法

### 星座
- 采：太阳/月亮/上升（若知道）、是否用星座解释自己或他人。
- 写：**「他用星座做什么」**——解释性格？解释关系？社交破冰？
- 不写：「因为天蠍座所以记仇」这类宿命结论。

### 紫微斗数
- 采：命盘（十二宫、主星）、本人对哪几宫最认同。
- 写：①十二宫 → 提问线索（事业/财帛/夫妻/子女/迁移/交友/官禄/田宅/福德/父母/兄弟/疾厄）
- ②本人认同度（例：「命宫天府，他说"守成"这条最像」）
- 不写：预测性结论。

### 周易 / 黄历 / 择日
- 采：是否择日、起卦习惯、看黄历的频率。
- 写：**决策习惯**——重大决定前是否等时机、是否需要外部确认系统。
- 这是行为线索，可进主结论的「决策风格」维度（标 C 级）。

### 其他（塔罗、MBTI、九型、八字）
- MBTI / 九型：归到「自我叙事」，同样标认同度。
- 八字：按紫微同法。
