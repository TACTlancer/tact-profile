# 三观与生活符号

## 一、先把词分清

| 层 | 问题 | 例子 |
| --- | --- | --- |
| **世界观** | 世界怎么运作？ | 人性善/恶、有秩序/随机、努力有用/命定 |
| **人生观** | 人为什么活？ | 意义在成就 / 关系 / 体验 / 传承 / 没有意义 |
| **价值观** | 什么更值得？ | 钱 / 自由 / 家庭 / 专业 / 名声 的排序 |
| **金钱观** | 钱是干什么用的？ | 工具 / 安全垫 / 身份 / 自由 / 赎罪 |

**金钱观是价值观的子项**，单独列是因为它最好观测（消费数据）。

## 二、宗教 / 信仰

**和玄学、意识形态要分开**：

| | 玄学（metaphysics.md） | 宗教 | 意识形态 |
| --- | --- | --- | --- |
| 性质 | 工具性（算命、择日） | 体系性（意义、戒律、共同体） | 政治性（权力、秩序） |
| 处理 | 附录，D 级 | 附录，A 级（本人自述） | 只记原话，不评价 |
| 能推 | 自我解释框架 | 意义来源、行为约束、共同体归属 | 无 |

**可写**：信仰身份（信/不信/不可知/不关心）、实践强度（每周/节日/偶尔/不实践）、行为约束（饮食、节日、捐赠、婚恋观、生死观）。

**区分「无信仰」的三种人**：
- 无神论：有明确立场，会主动谈
- 不可知论：不确定，不想争
- 不关心：没想过，视作生活默认值

这三种在画像里完全不同，不要合并成「不信教」。

**不写**：教派内部细节、他人信仰、宗教争论。
**不做**：评价、劝信/劝退、和科学对立化。

## 三、生活符号 → 三观（弱信号表）

**核心原则：单点不推，三点同向才写「倾向」。**

| 符号 | 可能含义 | 强度 | 敢说需要 |
| --- | --- | --- | --- |
| 饮食：素食/清真/明确忌口 | 信仰或健康约束 | 强（若有宗教背景）/ 弱（若为健康） | 本人说明来源 |
| 饮食：固定小店、老几样 | 稳定偏好、决策节省 | 弱 | 与其他「重复」倾向同向 |
| 饮食：一人食 vs 必须有人陪 | 社交取向 | 中 | 行为日志 |
| 色彩：黑白灰、低饱和 | 克制/低调/秩序 | 弱 | 至少两处一致（穿搭+房间+界面） |
| 色彩：高饱和、单色系 | 表达欲 / 秩序感 | 弱 | 同上 |
| 衣着：无 logo、同款多件 | 反符号 / 决策节省 | 中 | 持续 1 年以上 |
| 衣着：功能性优先 | 实用主义 | 中 | 与消费结构一致 |
| 衣着：品牌集中 | 身份表达 | 中 | 与社交场景一致 |
| 居住：极简 vs 囤积 | 控制感 / 安全感 | 中 | 本人承认 |
| 收藏（手办/唱片/书） | 意义附着、时间锚点 | 中 | 有维护行为 |
| 音乐：悲剧/治愈向 | 现实主义 / 修复需求 | 弱 | 与影视偏好同向 |
| 影视：偏好残酷结局 | 反圆满、现实主义 | 弱 | ≥2 条独立证据 |

## 四、拼图规则

> **六条通用规则见 `inference-rules.md`**（单点疑似 / 三点同向 / 行为优先 / 先找反例 / 不跨层 / 不用评价词）。这里只补「三观」特有的：

- **价值观 vs 行为**：说「不在乎钱」但消费结构重投入 → 以行为为准，标矛盾。
- **宗教 = emic 框架**：本人信什么就记什么，不判断对错、不做比较。
- **三观不靠自述定**：自述是 A 级，但要和行为对上；对不上就并列写。

## 六、红线

- 不贴标签：不写「佛系」「拜金」「精致利己」「精神资本家」。
- 不从饮食推宗教（除非本人说明）。
- 不从衣着推阶层或收入。
- 不评价信仰与价值观高下。
- 不把「年轻时的选择」当「一生立场」。
