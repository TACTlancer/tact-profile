# 隐私与脱敏规则

教育、家庭、身份这三类信息，价值高、风险也高。规则是：**写影响，不写细节；写结构，不写可识别信息；写到什么程度，先问本人。**

---

## 一、三档披露

| 档 | 谁能看 | 写什么 |
| --- | --- | --- |
| **公开档** | 可以给别人看 | 只写结构：工科背景、家庭支持型、南方长大 |
| **内部档** | 自己用（L2/L3 报告） | 层次、大类、地域、关系模式 |
| **本地档** | 只在本地文档、不导出 | 具体学校/单位，且本人明确授权 |

默认产出**内部档**。需要对外时自动降一档，不必再问。

---

## 二、教育经历

| 可写 | 需脱敏 | 不写 |
| --- | --- | --- |
| 学历层次（本科/硕士/博士） | 具体校名 → 「某 985 工科院校」「某市某高校」 | 学号、班级、宿舍 |
| 学科大类（工科/社科/艺术） | 专业全称 → 大类 + 方向 | 成绩单、排名明细 |
| 地域（南方/北方/一线/省会） | 具体年份 → 区间（"2017–2021"→"大学四年"） | 具体日期 + 具体地点的组合 |
| 在校行为（社团/竞赛/挂科/转专业/实习） | 导师/同学姓名 | 任何可反查的细节 |
| 对后来的影响 | | |

**组合检查**：校名 + 专业 + 入学年份 + 城市，四项同时出现基本等于实名。对外档至少去掉两项。

---

## 三、家庭描述

**先立一条原则：家人不是用户，没给过同意。**

| 可写 | 需脱敏 | 不写 |
| --- | --- | --- |
| 家庭结构（独生/有兄弟姐妹/单亲/隔代） | 父母职业 → 「体制内」「个体」「务农」等粗类 | 姓名、单位、职务 |
| 教养方式（控制/放任/支持/缺位） | 城市/地区 → 大区 | 收入、房产、具体经济数字 |
| 经济氛围（紧张/宽裕/不说） | 具体事件 → 只写影响 | 疾病、婚姻细节、冲突经过 |
| 你在家里的角色（长子/被照顾/照顾者） | | 家庭成员的隐私（病史、债务、纠纷） |
| 家庭对你的影响 | | 任何可被认出的第三人信息 |

**正确句式**：
- ✅「家里管得比较松，所以习惯自己做决定」
- ✅「有一个需要照顾的家人，所以时间安排受限」
- ❌「父亲是 XX 单位 XX 职，母亲因 XX 病……」

---

## 四、第三人原则

任何非本人信息，只保留「与本人的关系」和「对本人产生的影响」，其余删除。

- 朋友/同事：只写「有一个固定队伍」，不写人数、名字、平台 ID。
- 家人：只写结构与角色，不写个人情况。
- 伴侣：只写关系模式，不写对方身份与隐私。

例外：本人明确说「这段可以写」并愿意承担，才写，且仍做脱敏。

---

## 五、授权与撤回

1. **披露清单**：画像开头列「本人已授权写：X / 未授权：Y」。
2. **默认不写**：没问过的，按不授权处理。
3. **撤回即删**：本人说删，直接删，不留「已删除」标记，不记在 changelog。

---

## 六、自检清单（交付前）

- [ ] 校名/单位名是否只在本地档？
- [ ] 是否出现「学校 + 专业 + 年份 + 城市」四项组合？
- [ ] 家人信息是否只剩结构与影响？
- [ ] 有没有可反查的第三人姓名/ID？
- [ ] 披露清单是否写了？
- [ ] 对外档是否比内部档至少低一档？

---

## 七、案例（示范）

| 项 | 内部档 | 公开档 |
| --- | --- | --- |
| 教育 | 某 985 院校 · 信息类学院 · 2017–2021 | 某 985 工科院校，计算机相关，2017–2021 |
| 地缘 | 北方 A 市 → 南方 B 市 → 西南 C 市 | 北方出生，南方求学，西南工作 |
| 家庭 | （按本人授权写结构与影响） | 只写「家庭对你的影响」一句 |

对外引用时统一用公开档，内部报告保留内部档。
