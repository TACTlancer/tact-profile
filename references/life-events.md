# 健康与重大事件

这两类是画像里**解释力最强**的材料——它们决定了一个人什么时候变、为什么变、变到哪去。也是最容易越界的材料。

规则一句话：**写影响，不写病历；写应对，不写经过。**

---

## 一、可写 / 不写

| 可写 | 需本人明确授权 | 不写 |
| --- | --- | --- |
| 事件类型（生病/丧亲/事故/失业/搬迁） | 具体病名 | 病历、医院、医生、用药 |
| 时间（年到月） | 严重程度 | 检查报告、影像 |
| **对行为/决策/心态的影响** | 治疗过程 | 诊断标签（除非本人自述用） |
| 由此形成的应对模式 | 是否影响工作 | 家人/第三方的病情 |
| 长期限制（体力/作息/饮食/情绪） | | 可识别细节（罕见病 + 城市 + 年龄） |

---

## 二、健康

分三类，规则不同：

### 1. 身体限制 / 慢性病
- 写：限制类型（体力、久坐、饮食、睡眠、视觉、听力）、对玩法/工作/出行的影响。
- 写法示例：「长时间高强度操作会累，所以偏好可暂停、可分段推进的玩法。」
- 不写：病名（除非本人要求）、指标、用药。

### 2. 精神健康
- **最高敏感**。只写本人主动说过的，且只写「状态 + 影响」。
- 允许用本人自己的词（「那阵子很低落」），**不要翻译成诊断标签**。
- 不写：症状清单、量表分数、自伤细节、就医记录。
- 不做：临床判断（「可能是抑郁」）、劝医、疗效评价。

### 3. 睡眠 / 作息
- 可写：作息类型、是否需要固定时间、熬夜耐受。
- 这部分常和「节律」维度交叉，用 B 级证据（统计）即可，不必归入健康。

---

## 三、重大事件

| 类型 | 例子 | 可写 |
| --- | --- | --- |
| 丧失 | 亲人离世、分手、离婚 | 时间 + 影响 + 之后的行为变化 |
| 疾病 | 本人或家人重病 | 时间 + 对安排的改变 |
| 事故 | 受伤、车祸 | 时间 + 长期限制 |
| 家庭变故 | 离异、搬迁、经济危机 | 时间 + 角色变化（如提前承担） |
| 职业 | 失业、裁员、转行、创业失败 | 时间 + 决策逻辑变化 |
| 迁徙 | 跨省、出国、返乡 | 时间 + 社交/口味/习惯变化 |
| 其他 | 重大失败、被背叛、公开事件 | 时间 + 信任/边界变化 |

**只写三件事**：什么时候、改变了什么、之后怎么应对。

不写：经过、责任归属、情绪细节、他人评价。

---

## 四、怎么用（这是重点）

事件本身没意义，**影响才有意义**。每条事件必须落到至少一个下游维度：

| 事件 | 落到哪 |
| --- | --- |
| 生病 / 受伤 | 玩法偏好（容错、节奏）、职业选择、出行 |
| 丧失 / 分手 | 社交结构、审美（悲剧偏好）、信任模式 |
| 经济危机 | 消费观、风险偏好、储蓄习惯 |
| 迁徙 | 地缘认同、口味、社交重建方式 |
| 失业 / 转行 | 职业线、技能投入、焦虑来源 |

**应对模式**是最有价值的产出，常见几类：
- 收缩型：减少社交、缩回熟悉领域
- 补偿型：加倍投入某个领域（工作/游戏/学习）
- 重构型：换城市/换行业/换圈子
- 悬置型：先不动，等状态恢复

写进报告时用「他在 X 之后的应对方式是 Y」，比「他经历了 X」有用得多。

---

## 五、红线

1. 不推断——没说过的不写，包括「看起来像」。
2. 不做临床判断、不贴诊断标签、不建议治疗。
3. 不渲染痛苦，不写成故事。
4. 不涉及第三方病情。
5. 不因为「数据里有痕迹」就写（比如深夜发帖多 ≠ 抑郁）。
6. 本人说删就删，不留痕。

## 六、输出模板

```markdown
### 健康与重大事件

| 时间 | 类型 | 影响 | 应对模式 | 级别 |
| --- | --- | --- | --- | --- |
| 20XX | 身体限制 | 长时间操作疲劳 → 偏好可暂停玩法 | 收缩 + 分段 | A |

长期限制：__（体力/作息/饮食/情绪）
未谈：本人明确不想谈的部分
```

## 七、和别的维度怎么衔接

- **节律**：生病期/低谷期的活跃度变化，是节律断层的解释之一（但只能作「可能」，不能断言因果）。
- **消费**：医疗支出、康复投入单列，不进日常消费结构。
- **职业**：健康限制常是转行/降负荷的真实原因，比「想换个环境」更硬。
- **审美**：丧亲/重病后偏好的转变（治愈向 ↔ 悲剧向）是常见模式，但需 ≥2 条证据。
