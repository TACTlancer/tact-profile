# 兴趣域筛查（先探测，再提问）

**目的**：不追星的人不问追星，不看综艺的人不问综艺。避免题本空转，也避免把「不感兴趣」误记成「数据缺口」。

## 12 题雷达（2 分钟）

每题三档：**常看 / 偶尔 / 不看**。

| # | 问题 | 激活垂类 |
| --- | --- | --- |
| 1 | 看动画（番剧/剧场版）吗 | 动画 |
| 2 | 玩游戏吗（单机/联机/手游） | 游戏 |
| 3 | 看综艺吗 | 综艺 |
| 4 | 追真人明星/艺人吗（打榜、应援、追私生活） | 真人追星 |
| 5 | 消费偶像企划吗（LoveLive / 偶像大师 / BanG Dream / 赛马娘等） | 偶像企划 |
| 6 | 看剧集或电影吗 | 剧集 |
| 7 | 读非虚构、社科、思想类书吗 | 阅读/思想 |
| 8 | 有主动收藏/整理音乐的习惯吗 | 音乐 |
| 9 | 运动吗（健身/球类/跑步/户外） | 运动 |
| 10 | 在社交平台发内容吗（不只是看） | 社交/表达 |
| 11 | 关注玄学（星座/紫微/塔罗/择日）吗 | 自我叙事 |
| 12 | 关注行业/职业发展吗 | 行业/职业 |
| 13 | 会为爱好花钱吗（订阅/内购/周边） | 消费 |

### 4 与 5 必须分开问

| | 真人追星 | 偶像企划 |
| --- | --- | --- |
| 消费对象 | 艺人本人（关系、陪伴、应援） | 角色与作品（内容、设定、演出） |
| 典型行为 | 打榜、控评、追行程、买代言 | 抽卡、买 CD/BD、看 live、玩企划游戏 |
| 持续性 | 随艺人动向波动 | 随企划版本波动 |
| 画像含义 | 情感投射到**人**，需要「被回应」 | 情感投射到**设定**，需要「新内容」 |
| 风险点 | 塌房即退出 | 企划停服/完结即退出 |

混在一起会得出错误结论：「他喜欢偶像」→ 其实他喜欢的是**角色与企划世界**，对真人没有兴趣。这两类人的内容消费结构完全不同。

## 映射规则

| 回答 | 处理 |
| --- | --- |
| **常看** | 启用该垂类，走中/深卡 |
| **偶尔** | 启用该垂类，只出浅卡（型 + 1 条证据） |
| **不看** | **不启用**，记入「不适用域」，**不进缺口清单** |

## 「不看」怎么用（重要）

「不看综艺、不追星」不是缺失，是**结构信息**：

- 说明娱乐消费偏「内容向」而非「人向」（看作品，不追人）。
- 说明他不需要「陪伴型/下饭型」内容，更可能要「沉浸型」。
- 写进报告的「边界/不适用域」一节，措辞：**「不消费 X 类内容」**，不是「未提供 X 数据」。

## 题本裁剪

`question-bank.md` 的 100 问按垂类分组，**只展开已启用的域**：

- 已启用：问该域全部 10 问。
- 不适用：跳过，且不记缺口。
- 偶尔：问 3 问浅层。

## 与十维的关系

十维照常做（人都有时间、消费、表达）；垂类按雷达裁剪。**十维不因不追星而缺**，只是少了对应的子卡。
