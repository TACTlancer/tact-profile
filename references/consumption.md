# 消费倾向分析（钱花在哪 = 什么重要）

消费是**稀缺资源分配记录**，比自我报告更硬。但先排三个污染源，否则会读错：

| 污染源 | 表现 | 处理 |
| --- | --- | --- |
| 代付 / 家庭支出 | 账单里混着别人的消费 | 只取「本人确认为自己买」的项 |
| 礼物 | 收礼（不是偏好）/ 送礼（是社会关系） | 单列，不进偏好结构 |
| 一次性大额 | 装修、婚礼、搬家、治病 | 标「特殊项」，不参与日常结构 |

## 品类矩阵

| 品类 | 看什么 | 能推 | 不能推 |
| --- | --- | --- | --- |
| **数码硬件** | 更新周期、价位段、品牌集中度、是否折腾（DIY/刷机/配件） | 技术敏感度、参数党 vs 体验党、新事物容忍度 | 收入水平 |
| **服装百货** | 品牌 vs 无牌、单价段、频率、退货率 | 审美外显度、符号消费 vs 实用 | 品味高低 |
| **居住生活** | 房租占比、家居投入、搬家频率、独居/合租 | 生活品质权重、稳定 vs 流动 | 资产状况 |
| **饮食** | 外食/外卖比例、人均单价、探店 vs 固定店、健康投入 | 社交型 vs 独处型、仪式感、身体观 | 健康状态 |
| **运动** | 装备 / 课程 / 场地、频率、赛季性 | 装备党 vs 实用党、社交/独处驱动 | 体能水平 |
| **爱好（游戏/番/手办/乐器）** | 买断 vs 内购 vs 订阅、收藏 vs 体验、周边占比 | 收藏型 vs 体验型、沉没成本态度 | 喜爱度（买了≠爱） |
| **知识付费** | 课程完成率、订阅续费 | 学习动机（焦虑/实用/兴趣） | 能力水平 |

## 五个分析方法

1. **结构占比**：各类目年支出占比 → 价值排序。比重最高的两项才是「真在乎」。
2. **钱 vs 时间对照**：花大钱但少花时间的（如健身卡），是「愿望消费」；花小钱但高频的，是「日常依赖」。
3. **决策路径**：研究多久、比价次数、退货率、是否等折扣 → 计划型 / 冲动型 / 价格敏感型。
4. **周期**：一次性 / 订阅制 / 持续复购 → 承诺意愿。
5. **二手行为**：卖出（闲鱼/回收）频率 → 断舍离能力、沉没成本态度。

## 判别问题（进题本）

- 最近三个月最大的一笔「非必需品」支出是什么？
- 你衣柜里最贵的一件是什么？为什么买？
- 一个人吃饭你会怎么解决？
- 你为爱好花的钱里，最后悔的一笔是什么？
- 有没有买了但一次没用过的东西？
- 换手机/电脑是因为坏了，还是想换？
- 你会在什么情况下退掉已经买的东西？

## 输出卡

```
### 消费
- 型：体验型 / 收藏型 / 实用型 / 符号型（可组合）
- 结构：{top3 类目 + 占比}
- 决策：{计划/冲动} × {价格敏感/品质优先}
- 周期：{一次性/订阅/复购}
- 边界：不为什么花钱（明确不买的类目）
- 级别：A（账单）/ B（自述）/ C（推断）
```

## 红线

- 不推断收入、阶层、资产。
- 不评价消费「值不值」。
- 不把「贵」当「有品味」，也不把「省」当「抠」。
- 抽卡/内购单独看：它反映的是**对不确定性付费的意愿**，和买断消费是两种心理。
