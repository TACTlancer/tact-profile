# 输入源矩阵

| 平台 | 拿什么 | 拿法 | 主要偏差 | 能推 | 不能推 |
| --- | --- | --- | --- | --- | --- |
| QQ 空间说说 | 文本、时间、互动 | 登录 Cookie + API（见 tools/qzone） | 表演性、删帖、只留想留的 | 节律、表达、审美 | 真实情绪强度 |
| QQ 空间相册 | 图片、上传时间、描述 | 同上 | 只存"想留的" | 内容偏好、圈层、截图习惯 | 观看总量 |
| 微信朋友圈 | 生活节点 | 手动导出/截图（无批量 API） | 强筛选、分组可见 | 身份事件、社交面具 | 私下状态 |
| 微博 | 转发、原创、关注 | 网页抓取（有限流） | 情绪化、机器人 | 观点、圈子、即时反应 | 稳定立场 |
| 小红书 | 收藏、点赞、笔记 | 登录墙，手动导出 | 消费主义、种草 | 生活方式、消费 | 真实购买 |
| X / Twitter | 推文、关注链 | API（付费）/ 手动 | 英语圈、极化 | 信息源、亚文化 | 本地生活 |
| Facebook | 生平、关系 | 官方导出（JSON） | 中老年化、分组 | 人生阶段、关系 | 近期兴趣 |
| YouTube | 订阅、观看、评论 | Takeout 导出 | 推荐流污染 | 长尾兴趣 | 注意力实际分配 |
| Steam | 时长、成就、测评 | 官方 API / 页面 | 挂机、捆绑包 | 投入结构、完成派 | 喜爱度 |
| Bangumi | 收藏、评分、进度 | 网页导出 / API | 老二次元偏置 | 番剧结构、完成度 | 观看质量 |
| TapTap / 豆瓣 | 收藏、评分 | 手动 | 社区分 ≠ 个人分 | 接触面 | 个人评价 |
| 网易云 / Spotify | 歌单、循环 | API | 算法推荐 | 情绪底色 | 品味高低 |
| 日记 / 备忘录 | 内省、真实情绪 | **本人主动提供** | 无（最高价值） | 自我叙事 | 事件的客观性 |
| 玄学材料 | 命盘、星座、择日 | 本人提供 | 不可证伪 | 自我解释框架 | 任何事实 |

## 采集优先级

1. 有官方导出的（Steam / Bangumi / Facebook / YouTube Takeout）先导。
2. 有 API 的（QQ 空间 / 音乐 / 豆瓣公开页）写脚本抓。
3. 登录墙的（小红书 / 微博 / 朋友圈）用「本人手动导出 + 截图」。
4. 什么都没有的 → 走题本（question-bank.md）。

## 隐私处理

- 原始数据放 `tools/`，不进 `docs/`。
- 画像正文只引结论，不粘贴原文大段。
- 涉及他人（朋友/同事/家人）：只写结构（"有一个固定队伍"），不写名字/账号。
