# 访谈循环（持续校准）

## 定位：这是娱乐，不是任务

用户原话：

> 「我把这个当成一个休闲的娱乐，**不需要尽头**。」

所以这条机制的前提是：

| 是 | 不是 |
| --- | --- |
| 聊天式的随手校准 | 访谈提纲 |
| 随时可问、随时可停 | 有进度的项目 |
| **没有「问完」这回事** | 有完成度 |
| 有趣才继续 | 必须覆盖所有维度 |

**不要设「完成度」，也不要追求「问全」。** 他愿意聊就聊，不聊就放着——文档已经够用了。

---

## 为什么还要有这个机制

画像不是一次性产物，最大的风险是**一次成型后不再校准**：事实错了会一直错。

校准的时机不是「定期」，是**有话要说的时候**。

---

## 两阶段模式（重要）

画像不是「一次调研」，是**两个阶段**：

| 阶段 | 方式 | 产出 |
| --- | --- | --- |
| **首轮：大范围收集** | 一次性灌数据（说说/相册/对话/问答），建出初版 | L2 / L3 |
| **之后：休闲聊天** | 不设议题，聊到哪补到哪 | 持续增量 |

### 休闲聊天模式的规则

1. **不主动发问卷**——不当访谈员。
2. **聊到新东西就记**——顺手补一行，不打断对话。
3. **偶尔确认一句**——「这个要不要记进去？」
4. **可以给反馈，不只记录**——目的是**帮他更了解自己**，所以可以说「我注意到 X，你觉得呢」。
5. **不下诊断**——只描述模式，不评价人格。

> 核心区别：首轮是「采集」，之后是「陪他认识自己」。
>
> 用户原话：「允许用户在首轮大范围收集结束后以休闲聊天的方式逐渐完善自己的画像，**帮助他逐渐了解自己**。」

### 什么算「帮他了解自己」

| 可以做 | 不要做 |
| --- | --- |
| 指出他自己没注意到的重复模式 | 给他贴人格标签 |
| 把他的两句话放在一起对照 | 替他下结论 |
| 问「你当时为什么这么选」 | 分析他的童年 |
| 说「这条我可能读偏了」 | 说他「其实是 X 型人」 |

---

## 机制

```
1 有待确认项时（某条判断缺证据 / 某事实可疑），交付附带 1–2 个问题
2 没有待确认项时，不问，直接交付
3 答案写回文档 + 更新置信度
4 新冒出的疑问进清单
5 用户说「别问了」就停
```

**问题由「待确认清单」触发，不由「时间」触发。**

---

## 问题池（按类型）

| 类型 | 作用 | 例 |
| --- | --- | --- |
| **事实核对** | 防止整串判断建在错事实上 | 「XX 是 A 还是 B？」 |
| **归因确认** | 分清「自己选的」和「环境推的」 | 「这是你主动选的，还是被推着走的？」 |
| **语境确认** | 分清认真和玩梗 | 「这句是认真的还是图一乐？」 |
| **边界确认** | 防止写进不该写的 | 「这条能写进去吗？」 |
| **反例寻找** | 打破过度概括 | 「有没有相反的例子？」 |
| **程度校准** | 修正「太绝对」 | 「『总是』还是『有时候』？」 |

---

## 好问题的三个标准

1. **只有本人能答**——能查到的（生日、作品名）不算。
2. **答案会改变判断**——答完不改任何结论的问题没价值。
3. **不让人尴尬**——敏感区允许跳过，跳过不追问。

---

## 待问清单（模板）

放在画像文档的 §10 或单独一页：

```markdown
| # | 问题 | 为什么重要 | 状态 |
| --- | --- | --- | --- |
| 1 | | 会影响哪条判断 | 待问 / 已答 / 跳过 |
```

---

## 频次与节奏

| 场景 | 问几个 |
| --- | --- |
| 每写完一节 | 1 个 |
| 交付整篇 | 2–3 个 |
| 用户主动说「继续问」 | 4–5 个，分主题 |
| 用户说「别问了」 | 0，立刻停 |

**宁可少问，不要连问。** 一次 10 个问题会让人不想答。

---

## 问完之后必做

- [ ] 答案写回对应章节（不是只留在对话里）
- [ ] 受影响判断重判（见 `correction.md`）
- [ ] 置信度更新
- [ ] 一页版同步
- [ ] 清单里标「已答」

---

## 和「良质」的关系

波西格的良质：好不能被定义，只能在体验里被感知。

推到画像上：**准不准不能被推理证明，只能在访谈里被确认。**

但注意分寸——这是娱乐，不是艺术创作。**问到「够用」就好，不必逼近「完美」。**

---

## 反面模式（别做）

- 问能查到的事实（生日、作品名、数据）——自己查。
- 问开放到没法答的（「你是个什么样的人」）。
- 一次问十个。
- 问了不写回。
- 用户答「忘了」还追问。
