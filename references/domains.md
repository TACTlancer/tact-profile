# 垂类子画像模块

> **和 `dimensions.md` 的关系**：十维是**横切**（每个维度怎么推），本文是**纵切**（每个爱好怎么深挖）。两者正交——做垂类卡时，横切维度照样过一遍。
>
> 下结论前统一过 `inference-rules.md` 的六条规则。

通用十维回答「他是谁」，垂类模块回答「他在这个领域里是什么型」。

**用法**：先跑 `interest-screening.md` 的 12 题雷达，只对「常看 / 偶尔」的域启卡；「不看」的域不启用，记入「不适用域」。按数据挑 3–6 个垂类做，不要全做。每个垂类产出 1 张「子画像卡」（半页），可选并入 L2/L3 报告。

**统一卡片结构**：

```
### {垂类}
- 型：（一句话定性）
- 轴：（3–5 条，每条一句证据）
- 模式：（时间/节奏/消费习惯）
- 边界：（这个领域里他不做什么）
- 级别：A/B/C
```

---

## 1. 动画 / 番剧

- **轴**：题材（战斗 / 日常 / 恋爱 / 百合 / 机战 / 奇幻 / 悬疑 / 搞笑）、结构（季番 / 长连载 / 剧场版 / OVA）、驱动（追作者 / 追制作组 / 追声优 / 追原作）、审美点（角色 / 演出 / 音乐 / 剧情 / 世界观）
- **模式**：追更 vs 攒完看 vs 补旧番；单季集中度；重看率
- **边界**：明确不看的类型；弃番阈值（几集弃）
- **证据**：Bangumi / 相册截图日期 / 说说讨论

## 2. 游戏

- **轴**：体验形式（叙事驱动 / 竞技对抗 / 刷宝成长 / 建造经营 / 社交服务 / 探索）、付费习惯（买断 / 内购 / 订阅 / 二手 / 白嫖）、风格（题材 / 难度曲线 / 操作密度 / 容错窗口 / 叙事占比）
- **模式**：一口气通关 vs 长期日常；回坑周期；成就/完成度
- **边界**：退坑线（每日签到 / 数值墙 / PvP 压力）；不碰的品类
- **证据**：Steam 时长与成就 / 说说测评 / 78 相册

## 3. 综艺

- **轴**：类型（真人秀 / 竞技 / 谈话 / 生活 / 观察）、看的方式（下饭 / 专注）、偏好（冲突 / 温情 / 整活 / 烧脑）
- **模式**：追更 vs 攒；单集倍速；弃坑点
- **边界**：不看的题材（如选秀 / 恋综）

## 3b. 追星 / 偶像企划

**两个不同垂类，不能混**（判定见 `interest-screening.md` 第 4、5 题）。

- **真人追星**：轴 = 对象（歌手/演员/团体）× 参与度（只看 / 打榜 / 应援 / 追行程）× 消费（专辑/代言/演唱会）× 退出点（塌房/脱粉）。画像含义：情感投射到人，需要「被回应」。
- **偶像企划**：轴 = 企划（LoveLive / 偶像大师 / BanG Dream / 赛马娘 / 少女歌剧）× 参与（游戏/动画/CD/live）× 推谁（角色推 vs 声优推）× 投入（抽卡预算/周边/演出）。画像含义：情感投射到设定，需要「新内容」。

都**不追**就整块记不适用；只追企划的，不要写成「追星」。

## 4. 剧集 / 影视

- **轴**：产地（国产 / 日韩 / 欧美）、题材、节奏（追更 / 一次性刷完）、时长偏好（电影 / 短剧 / 长剧）
- **模式**：完成率；倍速习惯；二刷作品
- **边界**：不看的类型（恐怖 / 悲剧 / 慢节奏）

## 5. 阅读 / 思想

- **轴**：体裁（小说 / 社科 / 哲学 / 历史 / 技术）、作者谱系、读法（精读 / 速读 / 摘抄 / 听书）、影响深度（读过 vs 受影响）
- **模式**：阅读时段；笔记习惯；复读
- **边界**：读不下去的书；拒绝的立场
- **注意**：「喜欢某思想家」只记「他读了什么、引用什么」，不推断政治立场

## 6. 行业 / 职业

- **轴**：角色（执行 / 设计 / 决策 / 技术）、方法论（数据派 / 手感派 / 结构派）、倦怠点、跳槽逻辑（钱 / 成长 / 氛围 / 项目）
- **模式**：加班耐受；远程偏好；副业
- **边界**：不做的岗位类型；拒绝的公司类型

## 7. 意识形态 / 价值立场

- **红线**：**不推断**。只记录本人**明确表达**过的立场，原话引用，不评价、不归类。
- **做法**：列「他公开表达过的议题」+「态度方向（支持/反对/复杂）」+ 出处。
- **不做**：左右光谱打分、政党倾向推断、宗教推断。

## 8. 为人处世

- **轴**：沟通（直给 / 绕 / 看人下菜）、冲突（回避 / 正面 / 冷处理）、承诺（重 / 轻）、边界感（强 / 弱）、求助（主动 / 硬扛）
- **模式**：道歉方式；拒绝方式；被冒犯的反应
- **证据**：A（问答）优先，C 需 ≥2 条

## 9. 人际关系

- **轴**：结构（家庭 / 朋友 / 亲密 / 同事）、经营方式（高频低强度 / 低频高强度）、依赖度、公开度（是否让关系可见）
- **模式**：主动联系频率；节日仪式感；冲突后修复
- **边界**：只写结构，不写他人身份

## 10. 运动 / 身体

- **轴**：项目（球类 / 健身 / 跑步 / 户外 / 格斗 / 舞蹈）、风格（竞技 / 健身 / 休闲 / 户外）、驱动力（数据 / 社交 / 独处 / 健康）、频率
- **模式**：季节性强弱；装备投入；受伤史（若本人提）
- **边界**：不做的项目；放弃的运动及原因

## 11. 音乐

- **轴**：类型、使用场景（通勤 / 工作 / 睡前）、发现方式（推荐 / 追番 OP/ED / 朋友）、收藏方式（歌单 / 单曲循环）
- **模式**：循环期；现场演出参与

## 12. 消费 / 生活方式

- **轴**：消费观（值不值 / 体验 / 身份）、渠道（电商 / 二手 / 线下）、囤积 vs 极简、品牌忠诚度
- **模式**：大额决策周期；退货率；冲动 vs 计划
- **细化**：品类矩阵（数码/服装/居住/饮食/运动/爱好/知识付费）与分析方法见 `consumption.md`；出行/环保/居住/物品等行为符号见 `lifestyle.md`

## 13. 自我叙事 / 玄学

见 `metaphysics.md`。垂类只产出「他怎么解释自己」一段。

## 跨垂类交叉（最重要的产出）

做完 3 个以上垂类后，找**同一个内核在不同领域的重复出现**：

| 例子 | 交叉 |
| --- | --- |
| 「可恢复的难」 | 游戏容错偏好 × 运动风格（不玩极限） × 为人处世（不赌） |
| 「作者驱动」 | 动画追作者 × 阅读追作者 × 游戏追制作组 |
| 「纸片人入口」 | 动画角色驱动 × 游戏立绘偏好 × 收藏习惯 |
| 「每日签到即退坑」 | 游戏 × 运动打卡 × 社交维护 |

写进报告时单列一节「跨垂类内核」，这是画像从「清单」变成「人」的地方。

## 垂类深度

| 深度 | 内容 | 何时用 |
| --- | --- | --- |
| 浅 | 只有型 + 1 条证据 | 数据少 |
| 中 | 型 + 轴 3 条 + 模式 | 常规 |
| 深 | 全卡 + 边界 + 跨类交叉 | L3 |
