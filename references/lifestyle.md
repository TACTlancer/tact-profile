# 生活方式符号：出行 / 环保 / 居住 / 物品

消费讲「钱花在哪」，这一份讲「行为怎么发生」。两者要分开读：一个人可能省钱但环保、也可能大方但浪费。

---

## 一、出行方式

可观察：通勤工具、频率、距离、是否自驾、节假日怎么走、旅行方式。

| 观察 | 扩展出 | 强度 |
| --- | --- | --- |
| 打车 vs 地铁/公交 | **时间成本观**：愿不愿为省时间付钱 | 中 |
| 自驾通勤 | **控制感**、独立性、不愿被系统安排 | 中 |
| 骑行 / 步行通勤 | **身体观**：运动是否融入日常 | 中 |
| 长途自驾、夜间出行 | 风险偏好 | 弱 |
| 高铁/飞机频率 | **地理联结**：家在哪、和谁保持联系 | 中 |
| 旅行方式：自由行 / 跟团 / 度假村 | **探索型 vs 度假型** | 中 |
| 新能源车 | 环保 / 省钱 / 牌照，三种动机要分开问 | 弱 |
| 几乎不出门 | 空间半径小、线上生活为主 | 中 |

**最有价值的交叉**：旅行方式（自由行/探索）↔ 游戏偏好（探索型/开放世界）↔ 内容偏好（世界观宏大）。三者同向，就是「探索驱动」这个内核。

---

## 二、环保意识

可观察：垃圾分类、自带杯袋、二手、素食、节能、捐赠、可持续品牌、对浪费的态度。

| 观察 | 扩展出 | 注意 |
| --- | --- | --- |
| 自带杯/袋、固定习惯 | 规则内化（不是一次性表态） | 强 |
| 二手买卖 | 反消费主义 / 省钱 / 断舍离 | 三种动机要分 |
| 素食 | 环保 / 健康 / 宗教 / 口味 | 必须问来源 |
| 拒绝一次性用品 | 延迟满足、秩序感 | 中 |
| 「我一个人做也没用」 | **集体行动信任低** | 弱 |
| 高环保意识 + 高频飞行 | 一致性缺口，列矛盾不解释 | — |
| 对浪费的强烈反应 | 可能来自稀缺经历（家庭经济） | 需本人确认 |

### 关键区分：节俭 ≠ 环保

同样的行为（自带杯、少打车、买二手）可能来自四种来源：

| 来源 | 判别问题 |
| --- | --- |
| 省钱 | 「如果环保产品更贵，你还会买吗？」 |
| 环保 | 「你这么做是因为环境，还是因为划算？」 |
| 习惯 | 「家里从小就这样吗？」 |
| 控制感 | 「看到浪费会难受吗？」 |

分不清就别写，标「未确认」。

### 扩展到世界观：改变靠谁

| 立场 | 含义 |
| --- | --- |
| 个人责任型（从我做起） | 相信个体能动性 |
| 系统责任型（要政策/企业改） | 相信结构 |
| 无力型（做了也没用） | 低效能感 |
| 不关心型 | 议题不在视野内 |

这四型直接对应「他认为世界是怎么被改变的」，可以进世界观一节（C 级）。

## 三、居住

| 观察 | 扩展出 |
| --- | --- |
| 独居 / 合租 / 与家人同住 | 社交需求、隐私需求 |
| 搬家频率 | 稳定 vs 流动 |
| 家居投入（灯光/桌面/收纳） | 生活品质权重、秩序感 |
| 房间状态（极简/堆满） | 控制感、安全感 |
| 是否养宠物 | 照料意愿、责任结构 |

## 四、物品

| 观察 | 扩展出 |
| --- | --- |
| 同款多件、制服化 | 决策节省 |
| 长期使用旧物 | 沉没成本态度、怀旧 |
| 收藏（手办/唱片/书/票根） | 意义附着、时间锚点 |
| 频繁断舍离 | 反附着、轻装 |
| 修 vs 换 | 耐性、成本观 |

---

## 五、拼图规则

- 出行/环保/居住/物品都是**弱到中信号**，单点不推。
- 三点同向（如：骑行通勤 + 自带杯 + 二手 + 少外卖）才写「有一致的低消耗倾向」。
- 出现反例就降级，不强行解释。
- 不把「穷」读成「环保」、不把「环保」读成「道德高」。

---

## 六、红线

- 不从出行方式推收入（打车可能公司报销）。
- 不从环保行为推政治立场。
- 不评价「真环保/假环保」。
- 不用「精致/粗糙」这类评价词。
