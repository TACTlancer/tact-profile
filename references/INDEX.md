# references 索引

## 三条线

**流程线**（正常干活按这个走）
```
platforms → interest-screening → question-bank
   → dimensions（定义边界）
   → domains（垂类深入）
   → output-l1 / l2 / l3
```

**细化线**（按需取用，不是全读）
| 主题 | 读 |
| --- | --- |
| 钱怎么花 | `consumption.md` |
| 行为怎么发生 | `lifestyle.md` |
| 意义与信仰 | `worldview.md` + `metaphysics.md` |
| 身体与转折 | `life-events.md` |
| 亲密关系 | `sensitive.md` |

**横切线**：`privacy.md` —— 所有输出都要过一遍，不论级别。

## 交叉项分工（防重复）

| 主题 | 主文件 | 辅助 | 边界 |
| --- | --- | --- | --- |
| 消费 vs 生活方式 | `consumption`（钱：品类/结构/决策） | `lifestyle`（行为：出行/环保/居住/物品） | 一个讲钱，一个讲行为，不混 |
| 三观 vs 玄学 | `worldview`（四层结论） | `metaphysics`（材料怎么进，只进附录） | 玄学不参与三观结论 |
| 十维 vs 细化 | `dimensions`（只给定义与边界） | 各细化文件 | dimensions 不重复展开细节 |
| 健康 vs 生命线 | `life-events`（事件 + 影响 + 应对） | `dimensions` 第 8 维（旅程图） | 一个讲事件，一个画形状 |
| 亲密 vs 社交 | `sensitive`（亲密关系模式） | `dimensions` 第 6 维（社交结构） | 亲密是子集，单独处理因敏感 |
| 意识形态 vs 三观 | 都只记原话 | — | 不推断、不打分、不评价 |
| 筛选 vs 题本 | `interest-screening`（定域） | `question-bank`（提问） | 先筛后问，不筛不问 |

## 最小可用集

只做 L1 时，只需要：`interest-screening` → `question-bank` → `output-l1` → `privacy`。

其余文件全部跳过。

---

## 冲突时怎么裁决

1. `privacy.md` 优先于一切（隐私 > 完整性）。
2. **用户纠偏优先于任何推断**——事实层以本人说法为准，见 `correction.md`。
3. `sensitive.md` 的默认关闭优先于「数据里好像有」。
4. `life-events.md` 的「不写病历」优先于「这样更有说服力」。
5. 证据不足时，宁可进缺口清单，不写进结论。
