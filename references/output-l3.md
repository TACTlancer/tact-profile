# L3 重度画像模板

适用：有 ≥1 年全量日志，或本人明确要「完整版」。

篇幅：**分篇长文**（数万字），可拆成 8–12 篇。

## 篇章结构（可按数据裁剪）

| 篇 | 内容 | 主要证据 |
| --- | --- | --- |
| 00 导读 | 结论 + 证据链 + 置信度 + 阅读顺序 | 全部 |
| 01 档案 | 十维全表 + 设计/沟通需求清单 + 一页卡 | A/B |
| 02 时间轴 | 按年，阶段划分、转折点、断层 | B |
| 03 节律与行为 | 时段分布、峰值、断更、复发 | B（统计脚本） |
| 04 消费与完成度 | 时长/成就/退坑/二手 | B |
| 05 审美 | 番/游戏/音乐/图，作者与角色驱动 | B+C |
| 06 表达 | 语料分析、语气样本、语域 | B |
| 07 社交 | 结构、公开私密、关系类型 | B |
| 08 价值与道德 | WVS 4 维 + MFQ 5 基，含量表说明 | A |
| 09 旅程图 | 阶段图 + 关键事件表 | A+B |
| 10 缺口 | 不知道什么、怎么补 | — |
| 附录 | 自我叙事与象征系统（D 级） | D |

## 硬要求

1. **每条结论后挂证据**：`（B，docs/70 §2.3）`。
2. **置信度表**：高（直接陈述）/ 中（推断）/ 低（待确认）三档，逐条归类。
3. **矛盾单列**，不融合。
4. **变更记录**：本版相对上版改了什么。
5. **不写「我觉得」**：所有判断要么有证据，要么进缺口。

## 分篇写作顺序

先写 02 时间轴（骨架）→ 03/04/05（数据）→ 01 档案（汇总）→ 08/09（价值与旅程）→ 00 导读（最后写）→ 10 缺口。

## 一页卡（放最前）

L3 也必须有一页卡，供快速阅读。规则同 `output-l1.md`。

## 更新规则

- 新增数据 → 只改受影响的分篇 → 更新导读里的置信度 → 追加变更记录。
- 不要每次重写全部。
