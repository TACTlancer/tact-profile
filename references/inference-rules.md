# 推断规则（所有分析模块共用）

## 为什么单列

`worldview` / `lifestyle` / `consumption` / `domains` 原本各写一份「拼图规则」，内容 80% 重复。改一处忘另一处，规则就会漂。

**所以抽成单一源。** 各模块引用这里，不再自己写。

---

## 六条规则

| # | 规则 | 反例 |
| --- | --- | --- |
| 1 | **单点最多写「疑似」**，不进主结论 | 只看一件衣服不能说「他喜欢黑色」 |
| 2 | **三点同向才写「倾向」**——不同领域、同一内核 | 见下方组合示例 |
| 3 | **行为验证优先**：说的和做的不一致时，以行为为准，标矛盾 | 说「不在乎钱」但消费结构重投入 |
| 4 | **先找反例**：找不到反例才下结论；找到一个就降级 | 写「总是」前必须试过找「例外」 |
| 5 | **不跨层跳跃** | 「穿黑衣服」≠「悲观」；「吃素」≠「信佛」 |
| 6 | **不用评价词** | 「精致/粗糙」「真环保/假环保」「高级/土」 |

---

## 弱信号清单（单点不推）

| 类 | 例 |
| --- | --- |
| 出行 | 骑行 / 打车 / 步行 |
| 环保 | 自带杯、二手、少外卖 |
| 居住 | 租房 / 装修 / 收纳 |
| 物品 | 手机型号、键盘、杯子 |
| 外表 | 单件衣服、配色、发型 |
| 口味 | 一道菜、一个品牌 |

这些**只能当拼图块**，不能单独下结论。

---

## 组合示例

| 三点同向 | 可以写 | 不可以写 |
| --- | --- | --- |
| 骑行通勤 + 自带杯 + 二手 + 少外卖 | 「有一致的低消耗倾向」 | 「他环保」 |
| 黑衣服 + 听后摇 + 写诗 | 「审美偏好偏内敛」 | 「他悲观」 |
| 抽卡有硬上限 + 买断为主 + ROI 敏感 | 「对概率性消费有戒心」 | 「他抠门」 |

**区别**：前者描述**倾向**，后者给人**贴标签**。

---

## 反例处理

找到反例后：

1. 把结论降级：「总是」→「多数时候」→「有时候」→「曾经」
2. 把反例写进**矛盾清单**，不要抹平
3. 如果反例是「不同场域」，就写成**分场域判断**（参见 `prioritization.md` 的「过度压缩」）

---

## 和「时效」的关系

推断规则管**准不准**，时效管**还算不算数**。

两者一起用：

> 「多点同向 → 写倾向」+「长期 / 变化中 → 标时效」

一个判断要同时过这两关，才能进主结论。
